# E-Commerce Shopping Assistant

## Overview
AI-powered E-Commerce Chatbot built using Google Gemini and Streamlit.

## Features
- Product Recommendations
- Product Comparison
- Order Tracking
- Multi-turn Conversations
- Logging
- Error Handling
- Streamlit UI

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- python-dotenv

## Run Project

pip install -r requirements.txt

streamlit run app.py
